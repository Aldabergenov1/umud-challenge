UMUD Ultrasound Annotator — TIFF + scan-box calibration + safe legacy JSON import

Запуск (Windows/macOS/Linux):
1. Установите Python 3.9 или новее.
2. Откройте терминал в папке приложения.
3. Установите Pillow: python -m pip install Pillow
4. Запустите: python server.py
5. Откройте http://127.0.0.1:8000 (терминал оставьте запущенным).
6. Выберите папку data/raw/test_images_v2.
7. Выберите папку annotations.
8. Нажмите «Загрузить существующие JSON», чтобы безопасно импортировать уже созданную разметку.

Калибровка:
- Введите глубину depth_cm в сантиметрах (в том числе вручную, если глубина не напечатана на кадре).
- Поставьте точки 7 и 8: верхнюю и нижнюю границы бокса скана.
- mm_per_pixel = depth_cm * 10 / abs(scan_bottom_y - scan_top_y).
- Поставьте 2 точки верхнего апоневроза, 2 нижнего апоневроза и 2 фасцикула.
- Если глубина не указана на изображении, отметьте no_depth. В JSON будет no_depth: true. Если флажок выключен, ключ no_depth не записывается.

JSON:
- Сохраняются scan_top_x, scan_top_y, scan_bottom_x, scan_bottom_y, scan_box_height_px и points.scan_box.
- Кнопка импорта читает JSON из выбранной папки annotations и сопоставляет по имени файла.
- Старые JSON без scan_top_x/scan_top_y и без points.scan_box поддерживаются: их старые точки и метрики загружаются без ошибки. Старые метрики сохраняются до постановки новых точек бокса скана; после постановки двух точек масштаб и измерения пересчитываются.
- JSON без соответствующего изображения или с некорректным JSON пропускается; импорт ничего не записывает и не удаляет на диске.
- Экспорт/сохранение происходит только по отдельной команде пользователя.

TIFF:
TIFF-файлы конвертируются в PNG в памяти для отображения; исходные файлы не изменяются. Запускайте именно python server.py, а не python -m http.server.
